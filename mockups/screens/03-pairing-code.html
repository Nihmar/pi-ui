3 — Pairing code — manual fallback

Area
Onboarding
Behaviour
The pairing screen of #1 for a device without a camera (Linux, Windows, or Android with scanning refused): the code is typed or the link is pasted, and Pair sends it. The code is the credential — the QR carries the same one — so it is single use, expires after 10 minutes and is compared in constant time after normalization.
States to check
wrong code (attempts left, invite not consumed), expired code (10-minute TTL), rate limited (5 attempts/min/IP with Retry-After)
