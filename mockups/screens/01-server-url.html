Behaviour
The only pairing screen of a fresh install. The server's card (pi-ui serve on first run, pi-ui pair on demand) carries the origin, a one-time 6-character Crockford base32 code, the piui://pair?v=1&url=…&code=…[&fp=…] link and a QR. The address field takes either the origin or the pasted link; a pasted link fills the address and the code and pins its fp; the code is typed case-insensitively; the device name is prefilled. Pair exchanges the code for a device token kept in the OS keystore.
States to check
link pasted (address and code filled), unreachable server, wrong scheme (a browser URL is not a link), wrong/expired code and rate limiting (see 03), certificate trust (see 04)
