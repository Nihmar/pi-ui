28 — Host file browser

Area
Tools
Behaviour
The browser owns the host filesystem: a tree, a filter, and the markdown editor for text files. Read-only roots have no write path; editing writes through the server and respects the same path guards as everything else.
States to check
path outside the allowed roots, binary file, file changed on disk while open
