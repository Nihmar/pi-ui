One camera frame, one piui://pair?v=1&url=…&code=… payload: the origin, the 6-character code and — over TLS — the fingerprint to pin. The scanner hands it back to the pairing screen and pairing continues there.

pi-ui only scans with a camera you granted it. Nothing is lost: type the 6 characters from the card on the pairing screen — the same code pairs the same device.

this link expired
A pairing link lives 10 minutes and is single use, so a QR kept on screen or in a photo stops working. Print a fresh card on the server with pi-ui pair and scan it.

Scanning is Android-only (CameraX/ML Kit); on Linux and Windows the pairing screen takes the typed code or the pasted link instead.
