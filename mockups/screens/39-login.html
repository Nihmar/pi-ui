39 — Two-mode login

Area
Onboarding
Behaviour
Two independent ways in: a paired device token (operator scope) or the admin password, which mints a fresh admin-scoped device token. Both are revocable from Settings → Devices.
States to check
wrong password (rate limited), revoked token, admin sign-in on a public network warning
